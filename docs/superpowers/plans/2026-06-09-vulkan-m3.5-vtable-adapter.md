# Vulkan M3.5 — Vtable Adapter (refImport_t Translator)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the vendored Quake3e Vulkan renderer load and initialize correctly inside RealRTCW by interposing a thin translator that builds the renderer's expected refImport_t shape from engine's RTCW-flavoured one.

**Architecture:** Engine continues to populate the small RTCW refImport_t exactly as it does today. A new RealRTCW-authored translation unit `code/client/cl_refvulkan.c` allocates the big Quake3e-flavoured refImport_t and fills it slot-by-slot — either by aliasing the engine's existing function (for slots both structs share), by wrapping engine functions to match Q3e signatures (Microseconds wraps Sys_Milliseconds, Malloc aliases Z_Malloc, etc.), or by providing new code for slots that don't exist in RTCW (VK_CreateSurface uses SDL3's Vulkan API). When `BUILD_RENDERER_VULKAN=1`, `CL_InitRef` hands the big struct to `GetRefAPI` instead of the small one. OpenGL DLL load path is untouched.

**Tech Stack:** C99, RealRTCW engine internals (Cmd_AddCommand, Cvar_Get, Z_Malloc, etc.), vendored Quake3e `code/renderercommon/tr_public.h` (read-only — defines target struct shape), SDL3 (`SDL_Vulkan_GetInstanceExtensions`, `SDL_Vulkan_CreateSurface`), Vulkan loader (`vkGetInstanceProcAddr` from `libvulkan.dylib` via dynamic linker).

---

## Why this plan supersedes M2.4

M2.4 decision (`notes/decisions/2026-06-08-m2.4-vtable-adapter-shortcut.md`) chose a 12-line conditional `#include` in `code/client/client.h` over a ~400-line full adapter, on the assumption that the small and big refImport_t structs were nested supersets. The first runtime test of Vulkan DLL (2026-06-09) revealed they're **disjoint vocabularies** — engine assigns `ri.AddCoronaToScene`, `ri.Z_Malloc`, `ri.IN_Init`, `ri.Sys_GLimpInit` etc. (RTCW-only), and renderer expects `ri.Microseconds`, `ri.FreeAll`, `ri.inPVS`, `ri.VK_CreateSurface` etc. (Q3e-only). The `BUILD_RENDERER_VULKAN` define never reached engine TUs anyway, so the conditional was effectively a no-op all along; the build succeeded but the runtime vtable was misaligned. R_Init segfaulted after 8× `Cmd_AddCommand:  already defined` (empty command names = renderer called engine's `Cvar_VariableIntegerValue` thinking it was `Cmd_AddCommand`).

This plan replaces the M2.4 shortcut with a proper translator.

| `notes/decisions/2026-06-09-m3.5-vtable-adapter-proper.md` | Supersedes the M2.4 decision; documents the disjoint-vocabulary finding and the translator approach. |

```c
/*
 * cl_refvulkan.c — engine↔Vulkan-renderer vtable translator.
 * RealRTCW-authored. See cl_refvulkan.h for context.
 *
 * IMPORTANT: this TU MUST NOT include client.h. client.h pulls
 * code/renderer/tr_public.h which defines refimport_t as the SMALL
 * RTCW struct. This TU needs the BIG Quake3e struct from
 * code/renderercommon/tr_public.h. Including both causes a struct
 * redefinition error. We include the big one only and pull engine
 * function declarations directly from qcommon.h.
 */

#include "../qcommon/q_shared.h"
#include "../qcommon/qcommon.h"
#include "../renderercommon/tr_public.h"
#include "../sys/sys_local.h"
#include "cl_refvulkan.h"

/* The big refImport_t lives here as static storage. Filled lazily on
 * first call to CL_BuildVulkanRefImport; subsequent calls return the
 * same pointer. */
static refimport_t  vk_ri;
static qboolean     vk_ri_built = qfalse;

/* ====================================================================
 * Forward declarations of stub/wrapper functions defined later in this
 * file. Grouped by category for readability.
 * ==================================================================== */

/* Wrappers (Q3e signature ≠ engine signature) */
static int       vk_Microseconds( void );
static void     *vk_Malloc( int size );
static void      vk_FreeAll( void );

/* Vulkan-specific (no engine counterpart) */
static qboolean  vk_VK_CreateSurface( void *instance, void *outSurface );
static void     *vk_VK_GetInstanceProcAddr( const char *name );
static void      vk_VKimp_Init( void *windowDesc );
static void      vk_VKimp_Shutdown( void );

/* ====================================================================
 * Builder — fills vk_ri and returns its address.
 * ==================================================================== */

void *CL_BuildVulkanRefImport( void ) {
    if ( vk_ri_built ) {
        return &vk_ri;
    }

    Com_Memset( &vk_ri, 0, sizeof( vk_ri ) );

    /* --- DIRECT ALIASES: slots whose Q3e name and signature match an
     *     existing engine function 1:1. Fastest path. */
    vk_ri.Printf                    = (void (QDECL *)( int, const char *, ... ))Com_Printf;
    vk_ri.Error                     = (void (QDECL *)( int, const char *, ... ))Com_Error;
    vk_ri.Milliseconds              = Sys_Milliseconds;
    vk_ri.Cmd_AddCommand            = Cmd_AddCommand;
    vk_ri.Cmd_RemoveCommand         = Cmd_RemoveCommand;
    vk_ri.Cmd_Argc                  = Cmd_Argc;
    vk_ri.Cmd_Argv                  = Cmd_Argv;
    vk_ri.Cmd_ExecuteText           = Cbuf_ExecuteText;
    vk_ri.Hunk_Clear                = Hunk_ClearToMark;
    vk_ri.Hunk_Alloc                = Hunk_Alloc;
    vk_ri.Hunk_AllocateTempMemory   = Hunk_AllocateTempMemory;
    vk_ri.Hunk_FreeTempMemory       = Hunk_FreeTempMemory;
    vk_ri.FS_ReadFile               = FS_ReadFile;
    vk_ri.FS_FreeFile               = FS_FreeFile;
    vk_ri.FS_WriteFile              = FS_WriteFile;
    vk_ri.FS_FreeFileList           = FS_FreeFileList;
    vk_ri.FS_ListFiles              = FS_ListFiles;
    vk_ri.FS_FileExists             = FS_FileExists;
    vk_ri.Cvar_Get                  = Cvar_Get;
    vk_ri.Cvar_Set                  = Cvar_Set;
    vk_ri.Cvar_SetValue             = Cvar_SetValue;
    vk_ri.Cvar_CheckRange           = Cvar_CheckRange;
    vk_ri.Cvar_VariableIntegerValue = Cvar_VariableIntegerValue;
    vk_ri.Cvar_VariableString       = Cvar_VariableString;
    vk_ri.Cvar_VariableStringBuffer = Cvar_VariableStringBuffer;
    vk_ri.Cvar_SetDescription       = Cvar_SetDescription;
    vk_ri.CIN_UploadCinematic       = CIN_UploadCinematic;
    vk_ri.CIN_PlayCinematic         = CIN_PlayCinematic;
    vk_ri.CIN_RunCinematic          = CIN_RunCinematic;
    vk_ri.Com_RealTime              = Com_RealTime;

    /* --- WRAPPERS: Q3e expects different signature than engine provides.
     *     Defined further down in this file. */
    vk_ri.Microseconds              = vk_Microseconds;
    vk_ri.Malloc                    = vk_Malloc;
    vk_ri.FreeAll                   = vk_FreeAll;

    /* --- VULKAN WINDOW SYSTEM: code that doesn't exist on engine side.
     *     Defined further down. */
    vk_ri.VK_CreateSurface          = vk_VK_CreateSurface;
    vk_ri.VK_GetInstanceProcAddr    = vk_VK_GetInstanceProcAddr;
    vk_ri.VKimp_Init                = vk_VKimp_Init;
    vk_ri.VKimp_Shutdown            = vk_VKimp_Shutdown;

    /* --- INTENTIONALLY NULL: Q3e-only slots the RTCW gameplay code
     *     never asks for (Add*LightToScene, FinishBloom, etc.). If M4
     *     triage shows the renderer calls one of these, add a real
     *     stub here. Listed for grep-discoverability:
     *       AddAdditiveLightToScene, AddLinearLightToScene,
     *       CanMinimize, CL_IsMinimized, CL_LoadJPG, CL_SaveJPG,
     *       CL_SetScaling, Cvar_CheckGroup, Cvar_ResetGroup,
     *       Cvar_SetGroup, FinishBloom, GL_GetProcAddress,
     *       GLimp_EndFrame, GLimp_Init, GLimp_InitGamma,
     *       GLimp_SetGamma, GLimp_Shutdown, inPVS,
     *       SetColorMappings, SyncRender, Sys_SetClipboardBitmap,
     *       ThrottleBackend, VertexLighting.
     *     Com_Memset above zeroed all slots; NULL function pointers
     *     remain NULL. Renderer crashes with clean NULL-deref signal
     *     if any of these gets called — easy to diagnose in M4 logs. */

    vk_ri_built = qtrue;
    return &vk_ri;
}

/* ====================================================================
 * WRAPPERS — Q3e signature ≠ engine signature.
 * ==================================================================== */

/* Q3e wants microseconds; engine has Sys_Milliseconds returning int. */
static int vk_Microseconds( void ) {
    return Sys_Milliseconds() * 1000;
}

/* Q3e Malloc returns a tagged-zero allocation. Engine's Z_Malloc returns
 * the same shape; alias would work, but going via wrapper avoids future
 * signature drift if Q3e refines this slot. */
static void *vk_Malloc( int size ) {
    return Z_Malloc( size );
}

/* Q3e FreeAll = "release every tagged allocation owned by the renderer".
 * Engine's Z_FreeTags( TAG_RENDERER ) is the equivalent — but TAG_RENDERER
 * isn't defined in the engine. Use TAG_GENERAL as the conservative bucket
 * (matches what Z_Malloc above defaults to). If renderervk shows wrong
 * deallocation behavior, narrow to a renderer-specific tag. */
static void vk_FreeAll( void ) {
    Z_FreeTags( TAG_GENERAL );
}

/* ====================================================================
 * VULKAN WINDOW SYSTEM — placeholder stubs.
 * Task 5 will fill these with real SDL3/Vulkan code. For now they
 * Com_Error so we get an explicit panic if the renderer reaches them
 * before Task 5 lands.
 * ==================================================================== */

static qboolean vk_VK_CreateSurface( void *instance, void *outSurface ) {
    Com_Error( ERR_FATAL, "vk_VK_CreateSurface: stub — Task 5 not yet landed" );
    return qfalse;
}

static void *vk_VK_GetInstanceProcAddr( const char *name ) {
    Com_Error( ERR_FATAL, "vk_VK_GetInstanceProcAddr: stub — Task 5 not yet landed" );
    return NULL;
}

static void vk_VKimp_Init( void *windowDesc ) {
    Com_Error( ERR_FATAL, "vk_VKimp_Init: stub — Task 5 not yet landed" );
}

static void vk_VKimp_Shutdown( void ) {
    /* idempotent stub — safe to no-op on shutdown */
}
```

Locate the function (search for `vk_VK_GetInstanceProcAddr`). Replace body with:

```c
static void *vk_VK_GetInstanceProcAddr( const char *name ) {
    /* Returns address of a Vulkan function from the Vulkan loader.
     * Used by the renderer to resolve vkCreateInstance, vkGetDeviceProcAddr,
     * and the global instance-level entry points.
     *
     * Passes through to SDL3's Vulkan loader getter, which itself wraps
     * the platform-native vkGetInstanceProcAddr from /opt/homebrew/opt/
     * vulkan-loader/lib/libvulkan.1.dylib (linked in via Makefile, see
     * notes/reference/engine-map.md). */
    return SDL_Vulkan_GetVkGetInstanceProcAddr();
}
```

Note: `SDL_Vulkan_GetVkGetInstanceProcAddr` returns a function pointer (`PFN_vkGetInstanceProcAddr`). Q3e signature wants `void*` taking a name — slot impedance: caller pass `name` parameter through. Adjust to:

```c
static void *vk_VK_GetInstanceProcAddr( const char *name ) {
    static PFN_vkGetInstanceProcAddr loader = NULL;
    if ( !loader ) {
        loader = (PFN_vkGetInstanceProcAddr)SDL_Vulkan_GetVkGetInstanceProcAddr();
        if ( !loader ) {
            Com_Error( ERR_FATAL, "SDL_Vulkan_GetVkGetInstanceProcAddr: %s", SDL_GetError() );
            return NULL;
        }
    }
    /* `name == NULL` is Q3e's convention for "give me the loader entry";
     * non-NULL means resolve that specific function. */
    return (void *)loader( VK_NULL_HANDLE, name );
}
```

```markdown
# M3.5 — full vtable adapter (cl_refvulkan.c)

**Date:** 2026-06-09
**Phase:** Vulkan Phase 2, Milestone 3.5 (ABI carry-over from M3)
**Supersedes:** `notes/decisions/2026-06-08-m2.4-vtable-adapter-shortcut.md`

## Context

M3 closed with both renderer DLLs link-clean. First runtime test of the
Vulkan DLL revealed R_Init segfaults before vkCreateInstance — the
renderer's `ri.Cmd_AddCommand` arrived at the engine with an empty
string, repeating 8 times before crashing on the 9th.

Root cause: refImport_t vocabulary mismatch. M2.4 chose a 12-line
conditional include hoping the two structs were nested supersets. They
turn out to be **disjoint vocabularies** (~13 fields in small only, ~25
in big only, on top of the shared base). The conditional was also a
no-op because `-DBUILD_RENDERER_VULKAN` never reached engine TUs anyway
— but even if it had, the engine code populating `ri.Z_Malloc`,
`ri.IN_Init`, `ri.Sys_GLimpInit` etc. would have failed to compile
against the big struct that doesn't have those names.

## Decision

Build a proper RealRTCW-authored translator at `code/client/cl_refvulkan.c`:

1. Engine code throughout sees the small RTCW refImport_t consistently
   (revert M2.4's conditional include to always pull the small one).
2. `cl_refvulkan.c` includes only the big Q3e refImport_t in isolation
   from `client.h`, building it from scratch by assigning engine
   globals directly to big-struct slots (NOT by copying from engine's
   small `ri`).
3. `CL_InitRef` under `BUILD_RENDERER_VULKAN` calls
   `CL_BuildVulkanRefImport()` and hands the result to `GetRefAPI`.

Slot categories in the translator:
- **Direct aliases** (~25 slots): Cmd_*, FS_*, Cvar_* (Q3e and RTCW
  share these names + signatures).
- **Wrappers** (~3 slots): Microseconds (×1000 from Sys_Milliseconds),
  Malloc (alias of Z_Malloc), FreeAll (Z_FreeTags with TAG_GENERAL).
- **Vulkan window glue** (~4 slots): VK_CreateSurface (SDL3),
  VK_GetInstanceProcAddr (PFN passthrough), VKimp_Init (verify
  window), VKimp_Shutdown (no-op).
- **Intentionally NULL** (~13 slots): Q3e-only slots the renderer is
  unlikely to call from RTCW gameplay (Add*Light, FinishBloom, etc.).
  Listed in a comment block for grep-discoverability. If M4 triage
  shows a NULL deref on one of these, add a stub then — not pre-stub
  for hypothetical callers.

## Alternatives considered

- **A' (translator on renderer side)**: edit `code/renderervk/tr_init.c`
  to call engine names directly. Rejected — breaks vendor-prefix
  convention, makes future Q3e re-vendor painful.
- **B (refactor engine to Q3e vocabulary)**: rewrite engine code from
  `ri.AddCoronaToScene` to Q3e equivalents. Rejected — extensive
  engine code churn, risk of dropping RTCW-specific features.
- **C (drop OpenGL renderer)**: engine sees big struct only. Rejected
  — sacrifices OpenGL fallback that ragnar relies on while Vulkan
  matures.
- **D (extend engine refImport_t to superset)**: extend small struct
  with Q3e-only fields. Rejected after deeper review — required
  editing vendored `code/renderercommon/tr_public.h`, which would
  break vendor-prefix convention same as A'.

## Why

- **Vendored code untouched** — preserves vendor convention, makes
  future Q3e re-vendor a clean operation.
- **Upstream PR cleanness** — the diff for wolfetplayer/RealRTCW is
  one new file + ~10 lines in cl_main.c. Reviewable as «do you want a
  Vulkan adapter?» rather than structural surgery.
- **Single audit surface** — when M5+ effects don't render, the
  translation logic is in one file.
- **OpenGL fallback intact** — engine code path identical to before
  for OpenGL DLL load.

## Trade-off

- Adapter is one more file to maintain. ~500 lines of indirection.
- Indirection adds one extra function call to every renderer→engine
  callback (negligible perf, but real).
- Stubs for NULL slots will accumulate as M4-M5 triage discovers them.

## Revisit if

- A future re-vendor of Q3e changes the big struct shape significantly
  — update the adapter, not the engine.
- Future renderer (e.g. Metal native) needs another translator — copy
  this file as a template.
- Engine moves to Q3e vocabulary natively (Phase 4 hypothesis) — drop
  the adapter, but that's an explicit re-architecture decision.
```
